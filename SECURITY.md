# Security Policy

rDeckForge handles local template paths, AI handoff files, Office documents, generation history, and external renderer processes. Do not include real templates, business documents, private prompt packs, credentials, API keys, generated deliverables, local databases, or complete machine paths in public issues, pull requests, screenshots, or fixtures.

If a secret or private document is exposed, remove public copies where possible, revoke or rotate any credential, then report the incident privately through GitHub's **Security > Report a vulnerability** flow. Include the affected commit or version, reproduction conditions, and impact without publishing sensitive content.

The `0.1.x` line is a development preview. Release artifacts may require platform signing and notarization; see [RELEASE.md](RELEASE.md).
